# Premium pricing sources

## Nigeria property-market benchmarks

1. Private Property Nigeria, Estate Agent Packages: https://privateproperty.ng/estate-agents-packages
   The public page lists free seeker access and agent packages beginning at ₦10,000/month with listing limits, automatic boosts, manual boosts, sponsored listings, and analytics/reporting tools.

2. Nigeria Property Centre: https://nigeriapropertycentre.com/
   The public page positions browsing, saving, comparing, and contacting agents as free for property seekers, while agent-side value is based on listing exposure and lead tools.

These sources are contextual benchmarks only. NYSC premium prices are product-test recommendations, not claims about competitors' complete commercial terms.
